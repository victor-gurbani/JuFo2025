- **Node.js Version Incompatibility**: The server failed to start initially due to native module binding errors (`canvas`, `sqlite3`, `@tensorflow/tfjs-node`) caused by running Node.js v25.6.1. This was resolved by installing and using Node.js v22.22.0 via NVM and running `npm rebuild`.
- **Missing Permissions in JWT**: The `auth.js` login endpoint did not assign `VIEW_CARDS` and `VIEW_PERMISSIONS` to `guard`, `teacher`, and `tutor` roles, which would have prevented them from accessing the `/cards` and `/cards/:uid/permissions` endpoints. This was fixed by adding the missing permissions to the roles in `auth.js`.
- **Admin Permission Bypass**: The `checkAuth` middleware did not allow the `ADMIN_ALL` permission to bypass specific permission checks, which would have caused admins to be denied access to endpoints requiring specific permissions (e.g., `VIEW_CARDS`). This was fixed by updating `checkAuth.js` to check for `ADMIN_ALL`.
- **Missing Student Permissions**: The `auth.js` student login endpoint only assigned `STUDENT_ACCESS` to students, but the `student.js` endpoints required `VIEW_OWN_INFO`, `UPDATE_OWN_PHOTO`, and `UPDATE_OWN_INFO`. This was fixed by adding the missing permissions to the student role in `auth.js`.

- **Duplicate Variable Declarations in imageProcessor.js**: Lines 11-16 had duplicate `let imageBuffer`, `let processedImageBuffer`, and `let heicBuffer` declarations, causing a syntax error. This was fixed by removing the duplicate declarations (kept the first set).
- **Missing dotenv Dependency**: The `require('dotenv').config()` call was added to server.js but the `dotenv` package was not in package.json. This was resolved by running `npm install dotenv`.
- **Native Module Version Mismatch**: Node.js native modules (`canvas`, `sqlite3`) were built for Node.js v25.6.1 but `.nvmrc` specified v22. Resolved by switching to Node 22 via NVM and running `npm rebuild`.- **JSX Structural Mismatches**: Extensive deletions of manual wrapper components left behind trailing closing tags (e.g., `</ScrollView>`, `</>`) and disrupted the JSX tree across all 5 dashboard panels. This was fixed by carefully realigning the component trees.
- **TypeScript Promise Chain Errors**: Severe TypeScript compiler conflicts caused `finally does not exist on type IPromise` errors. This was traced back to an outdated `@types/axios` package which conflicted with Axios 1.7.9's native type definitions. Resolved by uninstalling `@types/axios`.
- **Strict TypeScript Errors**: Strict TypeScript configurations flagged `catch (error)` as `unknown` and `useRef<TextInput>(null)` as an invalid generic type usage. These were mitigated using explicit `any` typing to bypass blockers on existing legacy code.
